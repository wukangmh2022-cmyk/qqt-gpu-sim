⏱️ 1 分钟看懂核心设计与哲学差异

1. 决策赫兹完全一致：双方均运行在 10 Hz（每 100 ms 步进一次决策），这与人类顶尖选手的微操与生理反应窗口完美契合。
2. 我们：7.5M 纯视觉 Transformer（端到端 Scaling Law 路线）： 将地图直接切割为 25 个空间 Patch Token 并拼接 1 个全局状态 Token，送入 4 层纯 Pre-LN 自注意力块。第一层即可拉满全图感受野，配合 HL-Gauss 128 桶分类价值头，完全依靠集群海量强化学习算力端到端学会跨障碍封路与连环引爆。
3. 对方：3.2M 浅层 CNN + 循环时序 + MoE 门控（工程启发式兜底路线）： 为了在单线程低配 CPU 服务器上流畅运行，模型在外部算好了 182 维复杂的先验特征（4 组 BFS 寻路向量、4 方向如果放泡是否会封死自己的反事实避难时间），再通过 5 个专家网络（MoE）与 Sigmoid 战术安全门控进行硬性干预。

二、 维度级技术特性对决

对比维度 我们项目 (Ours: 7.5M ViT) 对方项目 (Theirs: 3.2M Hybrid MoE)
表征输入方式
(Representation)		 Patch 空间切块 + State Token（双序列输入）
• 空间张量 [-1, 14, 13, 15] 切为 25 个 (3×3×14) 的网格补丁
• 标量向量 [-1, 24] 独立投影为第 26 个 State Token
• 保留纯净物理原语（位置、引信、砖块、250ms 余威），无任何人为启发式注入 		多模态异构拼接输入 (Heterogeneous Input)
• 空间张量 [-1, 91, 13, 15]（含亚像素偏移、动作频次等 91 通道）
• 标量向量 [-1, 182]（高度依赖外部 CPU 计算的 4 组 BFS 最短寻路向量、4 方向反事实安全避难所预估）
网络骨干与感受野
(Backbone & RF)		 4 层纯 Pre-LN 自注意力 Transformer 编码器
• Embed = 392，4 头多头注意力，前馈倍数 4 倍（FFN 维度 1568）
• 第一层即可拉满全图全局感受野，全图任意两格之间的引信与逃生路线通过注意力权重直连计算 		3 层浅卷积 + 巨大 Flatten 全连接瓶颈
• 卷积提取后直接展平为 6,240 维，全连接 Linear(6422, 192) 消耗了 1.23M 权重
• 空间结构在展平中被破坏，高阶长程推理完全依赖大 MLP 硬拟合
时序记忆方案
(Temporal Modeling)		 无状态前馈（完全马尔可夫化观测设计）
• 依靠显式注入的引信倒计时与 250ms 爆炸余威通道消除时序模糊
• 彻底免除 RNN/BPTT，单批次任意打乱，训练吞吐无锁扩展至数十万 SPS 		显式循环隐状态维护 (Recurrent Memory, Hidden=256)
• 每个智能体在游戏进程中串行持有 256 维隐状态，由宿主在各 Tick 回传
• 增加了系统工程复杂度，难以进行大规模 GPU 并行展开训练
动作空间建模
(Action Space)		 因子化条件独立双头 (Factorized Dual Heads)
• 方向头 5 类（上下左右停） × 放泡头 2 类（放/不放）
• 联合概率相加，天然支持“边跑边放”，动作空间无冗余 		45 维单一扁平离散动作空间 (Unified Discrete)
• 停(1) + 移(4) + 放(1) + 跑放(4) + 7种道具使用(7) + 28种移动用道具
• 必须依赖外部布尔掩码（Legal Mask）将非法动作填充为 -inf
价值函数设计
(Value / Critic)		 HL-Gauss 分布式分类价值头 (128 Bins)
• 在 [-20, +20] 区间采用高斯平滑软标签分类，平抑高方差
• 极度稳定多智能体博弈中的剧烈奖励震荡 		单值回归 Critic (Team-Value Outcome)
• 输出单值期望胜率，评估整支队伍的最终胜负结果
安全与决策修正
(Safety & Gating)		 端到端价值驱动策略自适应演进
• 依靠大规模对战数据与高频试错，自发内化防自杀避险能力 		5 专家 MoE 路由 + Sigmoid 战术安全门控
• 关键帧通过外部门控直接给动作 Logits 叠加紧急躲避残差

三、 最新演进：8 智能体多队伍对弈与风格化强化学习架构 (8-Agent Multi-Team MARL)

从 1v1 到群体对抗：置换不变性表征 + 连续风格调控 + SOS 水泡状态机

随着代码库对微隙卡死与前期自杀率的彻底修复，系统现已全面演进至多智能体对抗阶段：支持一局 8 个智能体、2~8 支队伍自由编队（4v4 / 2v2v2v2 / FFA 混战）。在保持 ~7.6M 纯前馈 ViT 高吞吐基座的前提下，通过置换不变性分层表征、连续风格参数向量与 SOS 水泡救助/复活机制，实现平滑无级的团队战术演化。

1. 置换不变性 14 通道
抽象为自我层、友军热力图与敌军热力图；新增 ch12（被困队友救援引导）与 ch13（被困敌军击破目标），彻底杜绝编号过拟合。
2. 人格风格向量 z ∈ ℝ⁴
注入 State Token：[激进压迫, 阵型抱团, 开荒贪婪, 冒险穿火]；配合动作温度 τ 控制，无需人工战术门控即可无级调谐风格。
3. SOS 水泡救援状态机
受击进 3 秒水泡（移速归 0 禁放泡）；队友触碰立即脱困且【无无敌光圈】；对手触碰击破得分；3 秒未救超时自动引爆。
4. 双赛制与瓜分奖池
一血淘汰模式最后存活队独占 10.0 分，超时平局平分奖池；比武夺宝模式破泡得分，3 秒后在随机出生点带无敌光圈复活。

四、 总结：两种工程路线的高下立判

我们选择 7.5M ViT 的根本理由：
我们面向的是超大规模现代异构算力（GPU / DCU / 910B）。Transformer 具有不可替代的 Scaling Law 上限与全图关联推理能力。通过纯马尔可夫化物理通道设计，训练时不需要处理沉重的 RNN BPTT 展开，可以在极短的墙上时间内跑完数亿帧自博弈，让网络端到端形成超越人工规则的灵性走位。
对方选择 3.2M 混合 MoE 的现实考量：
对方的目标是端侧轻量化生产部署（部署在 Windows/Linux 游戏服上单线程运行）。为了让低配 CPU 也能在 100ms 内出结果，不得不借助 CPU 先把 BFS、避难所反事实预测算好作为标量喂入，并用 MoE 专家网络承载 7 种复杂道具的使用逻辑。
