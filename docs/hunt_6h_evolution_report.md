## 1. 任务背景与核心解决痛点

### 1.1 旧底模（it1100）的瓶颈：面对消极敌人“发呆”
在昨晚完成的 8 小时训练（`it1100`）中，模型在面对常规对战或高强度自博弈时表现出极高的战术素养，但暴露出严重的**“防御过剩、进攻消极”**缺陷：
1. **面对静止死靶（Idle Bot）**：由于死靶完全不放炮、不走位，模型感知不到危险，竟会在原地反复小范围打转或踱步，整场 1800 tick 发呆率高达 **62.2%**，均时 **1065 tick**，多次拖满 1800 tick 走向平局。
2. **面对漫游避战敌人**：缺乏主动拉近身位、连环下泡封死退路的“压迫感”，倾向于在自己的安全区等待敌人失误自杀。

### 1.2 破局方案：动静结合混合敌人池 + 攻防重构激励
为了在保持原有卓越生存与避险微操的基础上唤醒模型的追猎本能，本轮训练实施了以下关键革新：
1. **20% 规则敌人混合池（针对性特训）**：
   - **30% 静态死靶 (Idle Bot，占全场 6%)**：彻底不动不放炮，剥夺对手犯错空间，逼迫模型主动跨图索敌并下泡击杀。
   - **30% 纯漫游走位 (Roam Bot，占全场 6%)**：全图随机走位不放炮，训练在开阔地形与十字路口的围堵与截杀。
   - **40% 逃跑反击 (Flee Bot，占全场 8%)**：避开模型并在贴身时瞬间落雷，维持极高反杀警惕性。
2. **80% 高阶自博弈**：保留对抗演化的主要空间。

## 2. 退火机制深度拆解：当 $\alpha \to 0$ 时，模型还剩哪些奖励？

在训练日志中，后期持续显示 `α=0.00 lose=5.00`。很多开发者会关心：**退火归零后，是不是只剩下输赢二元奖励了？**

答案是：**绝不仅是胜负，而是卸下了“新手辅助轮”，保留核心博弈准则。**

### 2.1 退火归零（$\alpha = 0.00$）的辅助奖励
- **探索新格子奖励 (`explore_coef = 0.0`)**：彻底归零，杜绝模型在赛场上为了骗“新鲜度”分数而满图盲目逛街。
- **开局炸砖破墙奖励 (`brick_coef = 0.0`)**：彻底归零，不再为了刷分去无意义地炸偏僻砖块。
- **吃道具奖励 (`crate_coef = crate_reward_floor = 0.10`)**：**保留 10% 的保底底噪！** 源码中专门设计了 `crate_floor = 0.10`，防止在长达百亿步的深水区训练中，模型因为缺少即时反馈而“遗忘”吃速度鞋、药水和威力水晶的发育本能。
- **落败惩罚 (`lose_bonus = 5.00`)**：平稳收敛至固定 -5.0 分。

### 2.2 永不退火、100% 生效的核心博弈准则
代码中所有对抗核心奖励完全不受 $\alpha$ 影响，在整个生命周期中全额生效：

| 奖励项 | 设定值 | 战术引导意义 |
|---|---|---|
| **命中伤害 (`HIT_REWARD`)** | **+1.5 / -1.5** | 即时反馈：每对敌造成 1 点伤害获 +1.5，自身受伤扣 1.5。 |
| **互损换血惩罚 (`mutual_hit_penalty`)** | **-1.0** | 同 tick 双方互炸额外扣分，遏制伤敌一千自损八百的无脑肉搏。 |
| **优雅纯胜大奖 (`win_bonus`)** | **+6.0** | 击杀对手且本 tick 自身未受波及，赋予最高战术荣誉。 |
| **极限换命胜 (`trade_win_bonus`)** | **+3.5** | 虽受波及但成功杀死比赛，扣除互损后净收益约 +2.5 分。杜绝二极管惩罚，既鼓励终结比赛，又与优雅击杀拉开梯度。 |
| **双亡同归重罚 (`double_death_penalty`)** | **-5.0** | 双方同 tick 全部阵亡（0:0 暴毙）双输重罚！逼迫模型练就“杀人同时自身脱离爆心”的硬实力。 |
| **纯胜残血加成 (`win_hp_bonus`)** | **+0.5 × HP** | 满血获胜额外奖励，鼓励高容错、高健康度的精准斩杀。 |
| **时间流逝惩罚 (`step_penalty`)** | **-0.002 / tick** | 每存活 1 tick 扣 0.002 分（1800 tick 满扣 3.6 分），强力驱逐消极避战与挂机磨洋工。 |
| **超时平局双输惩罚 (`timeout_draw_bonus`)** | **-2.0** | 拖满 1800 tick 且双方血量相同，双双扣 2.0 分，拒绝消极默契球。 |
| **超时血差赏罚** | **+2.0 / -5.0** | 超时结算时，血量领先方获 +2.0，落后残血苟活方被重罚 -5.0。 |

> **退火核心哲学**：退火并不是去掉规则，而是将模型推入最残酷、最真实的**纯粹纳什均衡博弈**。想得分只有一条路——利用走位与泡泡杀死对手，并确保自己活下来！

## 3. 进化历程全景复盘

在 6 小时的长跑中，模型的战术风格经历了三个鲜明阶段：

```
[阶段一：破壳与阵痛 (it0~132)] 
打破原有保守习惯 → 疯狂尝试下泡 → 出现走位误伤与短暂自爆
               ↓
[阶段二：攻守再平衡 (it231~396)]
学会封路与拉扯 → 发呆率暴跌 50% → 面对死靶 300t 内快速斩杀
               ↓
[阶段三：宗师压迫与登堂入室 (it462~800)]
全地形压制 → 迷宫放泡翻倍 (33→65颗) → 对抗时空 A* 与死靶实现全维度碾压
```

### 阶段一：破壳与阵痛（Iter 0 ~ 132，0 ~ 16 亿步）
- **现象**：刚引入 20% 规则敌人池与进攻激励时，旧底模的“防御平衡”被强行打破。
- **代价**：模型开始激进下泡，但在拐角狭窄地形中容易封死自己，胜率一度出现短期波动。
- **收获**：成功打破了“能不动就不动”的思维定势。

### 阶段二：攻守再平衡（Iter 231 ~ 396，29 ~ 50 亿步）
- **现象**：放泡量呈井喷式增长，动作熵逐渐收敛，走位与下泡衔接顺畅。
- **转折点**：在 Iter 330 评估中，面对死靶的发呆率直接从 62% 跌落至 38%，平均击杀时间缩短至 400 tick 以内；面对时空 A* 猎人，学会了使用泡泡限制其走位空间。

### 阶段三：宗师压迫与全地形碾压（Iter 462 ~ 726+，58 ~ 95 亿步）
- **现象**：$\alpha$ 彻底归零，模型攻防一体，形成了令人惊叹的压迫式追猎风格。
- **实战数据对比（关键战场回测）**：

## 4. 下一阶段：9 小时宗师进阶长训规划 (9h Master Training)

鉴于本次 6h 训练已完美攻克“死靶发呆”难题，并淬炼出远超旧底模的火力与攻势，我们将在 800 iter 完赛后无缝开启下一轮 9 小时长训！

### 4.1 核心配置与目标
1. **训练规模**：12 节点 24 卡，计划 1200 Iterations（约 150 亿步增量，总体累计将突破 **240 亿步**）。
2. **底模继承 (Warm-Start)**：直接以本次完赛冠军模型 `params_it00000800_ema.pkl` 作为起跑线，传承其极高压迫感与零发呆特质。
3. **纳什均衡深水区博弈**：全流程处于 $\alpha = 0.0$ 的纯净对抗环境，进一步打磨：
   - 极限身位反弹推泡防守反击；
   - 复杂死角连环炸弹封杀；
   - 高速道具争夺与卡位。

### 4.2 自动化巡检与评估擂台池设计
继续沿用每 30 分钟自动化快照与对决巡检体系，考题梯度全面升级：

4. **静止死靶防呆巡检（3 局）**：确保闪电击杀耗时稳定在 200~300 tick 之间。
